# 📥 Voldena Download Manager

[🇹🇷 Türkçe sürüm](README.md)

A modern, fast, and feature-rich desktop download manager that accelerates and manages your file downloads efficiently.

## ✨ Features

- ⚡ **Accelerated Downloads**: Multiple connection segments for faster downloading.
- 🎨 **Modern UI**: Clean interface with real-time download speed graph and progress indicators.
- 🧩 **Browser Extension Integration**: Companion extension to capture downloads directly from your browser.
